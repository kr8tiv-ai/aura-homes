### Findings

1. **[MEDIUM] PR01's 3D canvas misses the headline pointer-up / Escape gate that the 2D editor already satisfies.** `PR01-direct-canvas.json:30–31` required: one drag is one undo step, commit on pointerup never per frame, Escape mid-drag emits *nothing* — "not an edit that undoes to the same place, nothing." Assert history length before and after. `GraphPlanEditor.tsx:359–414` does this: preview in local state, `onEdit` only in `finishDrag`. `GraphCanvasEditor.tsx:85–108` calls `onEdit` on every snapped `pointermove`. `:122–124` on Escape calls `onEdit(state.graph0, state.label)`, which is exactly the restore-edit the gate forbade. After a moved drag, history coalescing (`BuilderApp.tsx:420–423`) replaces the current doc with `graph0` and leaves the pre-drag doc on `past`, so Undo is a no-op step to the same house. `graph-canvas.spec.ts` has **zero** history-length or Escape assertions; `:312–326` only greps source strings. Fix: hold a candidate in local state, dispatch once on pointerup, and on Escape drop the candidate without calling `onEdit`. Pin `past.length` before begin, after move, after Escape, after a completed drag.
