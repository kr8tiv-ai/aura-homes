# AURA HOMES — "Come Home Again" (v2 — laid-back cut)
### Cinematic brand intro · 12 scenes × 10 seconds · built for Grok Imagine

**Runtime:** ~120 sec full cut · ~100 sec if you drop Scenes 9–10
**Format:** 16:9 master (crop 9:16 verticals from the same takes)
**Tone:** Laid-back and confident. Less movie trailer, more a guy who figured it out showing you around his land. Jokes stay dry. Nothing ever swells.

---

## HOW TO USE THIS

Grok Imagine has no memory between generations. Consistency comes from **repeating the same locked text in every prompt.** Every scene prompt below already includes the four locks — just copy the full scene block, paste, generate.

**Pro moves for consistency:**
1. Generate **Scene 3 first** to lock The Builder's face. Save your favorite still and use it as the image reference for every later scene he appears in (3, 5, 6, 11).
2. Never paraphrase the locks. Identical wording = identical world.
3. Generate 2–3 takes per scene, keep the best.
4. Keep frames **text-free** except the end card — burn in captions later if you want them.
5. Record the narration as **one continuous VO take** (full script at the bottom), then cut it over the visuals. One voice, one performance, zero drift.

**[BUILDER LOCK]** Recurring protagonist THE BUILDER: rugged man mid-30s, short dark beard, warm easygoing eyes, flannel shirt under a modern technical vest, weathered capable hands. Calm, unhurried, never posed. Same man every scene.
